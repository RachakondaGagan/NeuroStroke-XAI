# NeuroStroke-XAI

Explainable Deep Learning Web Platform for Early Brain Stroke Detection and Clinical Decision Support.

## Current development flow
1. CT 3-class pipeline
2. MRI 3-class pipeline
3. Core CT/MRI integration
4. XAI, risk assessment, and web application
5. Stroke subtype classification
6. Final integration and evaluation

## Dataset placement
Place the downloaded TEKNOFEST dataset ZIP in:

`data/raw/`

Do not extract or rename the dataset until the dataset audit step.
